# HS / SYNC v1.0.0

首个正式版本：用于多相机同步观察与现场展示的 Android 计时器。

- 默认黑底红字极简展示，自动放大 `分:秒.毫秒`，支持白字切换。
- 完整同步测试靶包含横向扫描条、绘制序号和 16 位 Gray 编码。
- 支持暂停、继续、归零、全屏和横竖屏切换，屏幕保持常亮。
- 单调时钟驱动全部标记，分钟持续累加。

## 安装

下载 `ms-clock-v1.0.0.apk` 安装，最低 Android 7.0（API 24）。
此 APK 使用独立正式签名，无法覆盖之前使用 debug 签名安装的测试版；先卸载旧测试版再安装，会清除旧应用数据。后续正式版使用相同签名更新。

`SHA256SUMS` 用于检查 APK 完整性；`signature.txt` 包含签名验证结果及证书指纹。

## 验证与限制

发布流水线必须通过 Debug / Release 构建及两种变体的 Lint 后才签名发布。
2026-09-09 已完成 OnePlus PLF110 上的功能实测；这是此前调试版的验证记录，不代表本次正式签名 APK 已重新实机验证。

毫秒显示不等于毫秒光学分辨率；精度受屏幕刷新、扫描及相机曝光影响。应用只提供拍摄靶，不控制四路相机，也不自动计算同步误差。
